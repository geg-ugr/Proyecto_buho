# Proyecto BUHO

**BUHO** es un proyecto de **B**ajo-coste dirigido a la educación **U**niversitaria para el desarrollo de **H**erramientas **O**pen-source.

Este proyecto tiene como objetivo proporcionar una serie de experimentos prácticos y educativos enfocados en el electromagnetismo y los circuitos eléctricos, utilizando materiales y equipos accesibles. Los experimentos están diseñados para estudiantes que se encuentran en sus primeros años de ingeniería o ciencias físicas, con un enfoque en el aprendizaje a través de la experimentación directa.

Para ello, se proporcionan por un lado diseños de [componentes](#componentes) que se pueden utilizar como herramientas/instrumentos/materiales en las distintas [prácticas](#prácticas).

Los componentes diseñados intentan ajustarse a estos dos objetivos:

1. Se priorizará el uso de materiales de bajo coste: empleando materiales disponibles en ferretería, impresión 3D, etc.
2. Los desarrollos son abiertos y se aportándose toda la información necesaria para fabricarlos o modificarlos.

Sin embargo, estos dos objetivos no son compatibles al existir herramientas o instrumentos comerciales que ya de por si tienen un coste muy bajo. En esos casos se ofrecen sugerencias de marcas comerciales.
